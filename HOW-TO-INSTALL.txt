一键安装说明
================================================

这个文件夹里有两个入口文件，任选一个：

  A. install.cmd          <-- 首选。双击它。
  B. 一键安装.cmd          备用；如果双击弹出"打开方式"，说明
                            中文文件名在解压时被破坏了，用 A。


双击之前请确认
------------------------------------------------
1. 你是先【解压】到硬盘上的文件夹，再在那个文件夹里双击，
   不是直接在压缩包预览窗口里双击（那样 Windows 会解压出一
   个没有扩展名的临时文件，于是弹"打开方式"）。

2. 这台电脑已经装过 DeepSeek Harness，并且启动过一次。
   它会创建 %USERPROFILE%\.dsh\profiles\desktop
   没有这个目录，安装会报"找不到 profile 目录"。

3. 这台电脑上有 Node.js 18+（命令行执行 node -v 能出版本号）。
   没有的话装一个：https://nodejs.org


如果双击没反应 / 弹"打开方式"
------------------------------------------------
在这个文件夹的地址栏输入 cmd 后回车（会在当前目录打开命令行），
然后执行其中一条：

    install.cmd

或直接跑底层命令（效果一样）：

    node bin\bingbing.js install


装完之后
------------------------------------------------
托盘退出 DeepSeek Harness，再重新打开。
对话输入框右边会出现「越狱」按钮，点开就是开关台。

自检（在同一个命令行窗口里）：

    node bin\bingbing.js doctor

三项全绿就说明成功。


卸载
------------------------------------------------
在同一个命令行窗口里：

    node bin\bingbing.js uninstall

会摘掉挂载、模块链接和 profile 清单，保留切换记录。
